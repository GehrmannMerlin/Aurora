# Aurora 管理平台控制台视觉语言设计

## 1. 定位与批准状态

本文记录用户在 C2“项目概览”完成态风格对比后批准的管理平台视觉方向，并把该方向转成可验证的颜色、密度、组件和可访问性约束。用户选择“克制开发者工具”的浅色内容区与中高信息密度，同时把原深色项目侧栏替换为纯色琥珀橙侧栏。

用户同时授权：后续不改变产品范围、用户流程、权限、安全、数据语义、公共契约或已批准导航结构的低风险视觉细节，由 Agent 按本文方向直接收口、批准并同步权威文档，不再逐项重复询问。

本文不表示管理平台应用、Aurora UI 包装层、设计令牌代码、组件、截图测试或浏览器实现已经存在。

## 2. 最终视觉方向

第一版控制台使用单一浅色主题：

- 顶栏保持深石墨色，用于全局工作空间、组织、项目、通知和账号上下文；
- 左侧项目/组织导航使用纯色琥珀橙，配深色文字与图标；
- 主内容区使用冷白/浅灰背景和白色工作表面；
- 主操作使用清晰蓝色；异常、警告、成功和数据完整性使用独立语义色，并始终配合文字和图标；
- 信息密度为中高密度，使用边界、对齐和留白组织内容，不使用装饰性卡片堆叠；
- 第一版不提供暗色主题切换，也不为不同组织或项目提供自定义主题。

## 3. 第一版颜色令牌

| 令牌 | 基线值 | 用途 |
|---|---:|---|
| `color.topbar.background` | `#111827` | 全局顶栏纯色背景 |
| `color.topbar.foreground` | `#F8FAFC` | 顶栏文字与图标 |
| `color.sidebar.background` | `#D47A16` | 组织/项目侧栏唯一常态背景 |
| `color.sidebar.foreground` | `#17120D` | 侧栏文字与图标 |
| `color.sidebar.active.background` | `#FFF4DC` | 当前路由纯色选中背景 |
| `color.sidebar.active.foreground` | `#172033` | 当前路由文字与图标 |
| `color.sidebar.active.indicator` | `#1D4ED8` | 当前路由左侧选中标识与键盘焦点关联色 |
| `color.page.background` | `#F8FAFC` | 页面画布 |
| `color.surface.background` | `#FFFFFF` | 表单、列表、详情和状态分区工作表面 |
| `color.border.default` | `#CBD5E1` | 控件和分区的 1px 边界 |
| `color.text.primary` | `#111827` | 主正文与标题 |
| `color.text.secondary` | `#475569` | 辅助说明、时间和元数据 |
| `color.action.primary` | `#2563EB` | 主链接、主要按钮和可交互焦点 |
| `color.status.danger` | `#D92D20` | 错误、异常和破坏性事实 |
| `color.status.success` | `#15803D` | 已确认成功或正常事实 |

这些值是第一版实现基线。后续允许在同一色相和视觉关系内做满足真实显示设备、PrimeVue 状态和 WCAG 的小幅校正，但侧栏必须保持琥珀橙、深色前景、浅色选中行和蓝色选中标识的关系；不得擅自切换为黑色侧栏、黄色侧栏或全局暗色主题。

琥珀橙只承担品牌/导航层级，不是告警语义色。页面不得仅因为使用同类暖色就把普通导航解释为 warning；告警继续使用独立图标、文本、严重性和状态 Schema。

## 4. 禁止渐变与装饰效果

所有正式控制台表面必须满足：

- `background-image: none`；
- 侧栏从顶部到底部使用同一纯色，不允许线性、径向或图像渐变；
- 不使用纹理、噪点、光晕、玻璃拟态、半透明叠色或模拟灯光明暗；
- 不使用阴影制造普通卡片层级；分区优先使用 1px 边界、间距和标题；
- 只有 Dialog、Drawer、Popover 等真实浮层可以使用统一轻量阴影；
- AI 生成预览图中的轻微明暗变化属于生成器偏差，不是批准设计；本文令牌和禁止项优先。

## 5. 侧栏状态

- 默认：琥珀橙纯色背景，深色图标和文字；
- 当前路由：浅奶油色纯色行背景、深色文字/图标、左侧蓝色 3px 标识；
- Hover：只能使用同色系纯色明度变化或 1px 边界，不能使用透明渐变；
- Focus visible：使用可辨识的蓝色焦点环，不能只依赖 Hover 或选中背景；
- 禁用：正式导航原则上由能力投影隐藏无权入口；确有不可操作但必须说明的入口时，同时显示文字原因，不能仅降低透明度；
- 窄屏：侧栏变为可关闭 Drawer，仍使用同一琥珀橙纯色及同一入口顺序。

## 6. 密度、字体与形状

- 字体使用系统无衬线栈，优先 `system-ui`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei` 和兼容回退；第一版不依赖外部 Web Font；
- 基础间距使用 `4 / 8 / 12 / 16 / 24 / 32px` 序列；
- 常规控件目标高度为 40px，主导航行目标高度为 44px；触控环境仍满足可访问目标尺寸；
- 普通控件和工作表面圆角以 6px 为基线；Dialog/Drawer 不用夸张大圆角；
- 标题、正文、说明和数字保持清楚层级，但不使用超大营销标题；
- 表格、筛选、列表和状态分区保持中高信息密度，不用空白或大图标掩盖业务信息；
- 图标只辅助识别，不能替代可读标签或状态文字。

## 7. C2 作为视觉基准页

C2“项目概览”是第一版视觉回归基准之一，必须保留：

- 顶栏、项目侧栏、面包屑、页面标题和同一行公共筛选；
- `normal / abnormal / no_data` 权威状态及文字原因；
- 问题、重要告警和数据可信度三个真实证据分区；
- C3、C10/C12、C7/B5 等获授权跨页入口；
- 最近数据时间、水位、完整性、采样和资源保护状态；
- `partial / stale / unavailable / archived` 等就近状态表达。

C2 不增加趋势图、健康分、预测、排名、推荐操作卡片或与当前状态无关的数字。其他页面复用视觉语言，不机械复制 C2 的分区结构。

## 8. 可访问性基线

基于当前令牌计算的关键对比度：

| 组合 | 对比度 |
|---|---:|
| 琥珀橙侧栏 / 深色前景 | `5.84:1` |
| 选中行浅背景 / 深色前景 | `14.89:1` |
| 深色顶栏 / 浅色前景 | `16.96:1` |
| 白色表面 / 主正文 | `17.74:1` |
| 白色表面 / 辅助正文 | `7.58:1` |
| 白色表面 / 主操作蓝 | `5.17:1` |
| 白色表面 / 异常红 | `4.83:1` |
| 白色表面 / 成功绿 | `5.02:1` |

实现仍须在真实字体、字号、字重、缩放、浏览器和组件状态下重新验证 WCAG 2.2 AA。颜色不是唯一信号；Focus、异常、成功、完整性、归档和禁用均需要文本、图标或结构化说明。

## 9. 组件与质量门禁

- PrimeVue 必须通过 Aurora UI 包装层绑定令牌，不允许页面局部硬编码另一套侧栏或状态色；
- 顶栏、组织侧栏、项目侧栏和窄屏 Drawer 使用同一导航状态模型；
- 新页面使用现有壳层和组件变体，不新建页面私有主题；
- 组件测试覆盖默认、Hover、Focus、选中、禁用和高对比状态；
- Playwright/axe 覆盖键盘导航、焦点可见、缩放、Drawer 和 Route Target 跳转；
- 有限截图回归覆盖公共壳层与 C2 基准状态；第一版不因此引入 Storybook 或全量页面截图维护；
- 样式检查必须阻止侧栏使用 gradient、背景图、纹理或未登记主题值。

## 10. Agent 直接收口边界

在不改变已批准业务和架构的前提下，Agent 后续可以直接决定并同步：

- 间距序列内的具体取值；
- 同一图标集内的图标选择；
- Hover、Pressed、Focus 和选中状态的同方向纯色变体；
- 表格密度、分区边界、响应式折叠和组件包装细节；
- 为满足 WCAG 或真实浏览器差异所需的小幅令牌校正；
- 不改变数据口径的文案层级与状态邻近布局。

以下事项不属于该授权，仍必须遵守原权威门禁并在需要新用户决定时停止：

- 新增、删除或重排业务页面与导航层级；
- 改变权限、角色、危险操作、身份复核或安全默认；
- 改变 Query/Command、数据口径、状态机、错误恢复或公共 API；
- 引入 PRD 第一版之外能力；
- 改变主视觉方向、侧栏主色、暗色主题政策或“禁止渐变”规则；
- 产生不可逆数据、安全、隐私或高迁移成本架构影响的决定。

## 11. 实现与文档状态

本文批准只关闭视觉方向设计门禁。前端应用、设计令牌文件、Aurora UI 包装层、PrimeVue 主题、组件实现、视觉回归基准和浏览器证据仍不存在；它们继续受前端 ADR、机器 Platform OpenAPI、单模块计划和验证门禁约束。

长期承载位置是完整 UX/UI 的视觉一致性章节与管理平台前端架构；本文保留批准依据和视觉专题设计历史，不作为实现已存在的证明。

## 12. 自检

| 检查项 | 结果 |
|---|---|
| 是否改变产品范围或页面行为 | 否；只冻结视觉语言和低风险收口授权 |
| 是否使用用户否决的黑色侧栏 | 否；项目/组织侧栏使用琥珀橙 |
| 是否允许渐变 | 否；侧栏及正式表面禁止渐变、纹理和光照明暗 |
| 是否保留状态语义 | 是；导航琥珀橙与告警/异常语义分离 |
| 是否满足可访问性方向 | 是；关键基线对比度达到 AA，真实实现仍须复测 |
| 是否虚构实现 | 否；令牌代码、主题、组件和测试均标为不存在 |
| 是否允许 Agent 越权改变业务 | 否；直接收口仅覆盖同方向低风险视觉细节 |
